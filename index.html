Catch traffic surges by how fast they grow

We model each network protocol as a function of time. Derivatives, integrals and eigen-analysis, written as matrix operations, flag an attack while it is still building, before a fixed volume threshold would react.

Overview

A fixed threshold is always late

Most monitoring tools raise an alarm only when traffic volume crosses a fixed level. By then an attack is already large, and a level high enough to ignore busy hours also misses a slow escalation. This project watches the rate of change instead.

Typical Static volume threshold

  • Fires only after the flood is already large
  • One number has to cover quiet and busy hours
  • Misses slow, deliberate escalation
  • Says nothing about which protocols moved together

This project Rate-of-change detector

  • Reacts while the surge is still developing
  • The sign of f′ separates onset (+) from recovery (−)
  • A median/MAD baseline is not inflated by the attack itself
  • The covariance eigenvector shows which protocols surged together
Background

Queiroz et al. build time-aligned traffic indicators for software-defined networks and score deviations with mean and standard deviation. They note that real traffic is bursty and heavy-tailed, and name median and MAD as the robust alternative without evaluating it. This project applies that robust baseline to the rate of change rather than the traffic level.

W. Queiroz et al., “A multi-level traffic analysis framework for software-defined networks,” Computer Networks, vol. 289, 112701, 2026. doi:10.1016/j.comnet.2026.112701
Approach

From packet capture to anomaly report

Every stage is a matrix operation on the traffic matrix T, so each step processes all protocol channels at once.

    Mathematics

    Calculus, written as matrices

    The samples are equally spaced, so each calculus operation becomes a sparse, banded matrix. One multiplication applies it to every channel.

    Limitations

    • Onset, not classificationIn the steady middle of a long flood, traffic is flat and f′ ≈ 0. The detector fires at the start and the end.
    • Malicious or legitimateA flood and a large file transfer both rise quickly. Pair the detector with a volume rule and a check of source addresses.
    • ScaleA day at 1-second samples gives 86,400 columns. S, D and A are banded, so sparse storage keeps memory and time small.
