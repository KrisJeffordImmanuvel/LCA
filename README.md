# LCA — Rates of Change in Network Traffic

Team 7 micro-project for **25DC201 Linear Algebra and Calculus for Data Science and Cybersecurity Engineers**, Karunya Institute of Technology and Sciences.

The website (`index.html`) is a single self-contained page with an overview, the method, the mathematics, a live in-browser demo, results, the Python implementation and the team. In the demo, a synthetic traffic matrix is smoothed, differentiated and integrated with banded operator matrices, then scored with a robust median/MAD z-score and checked with eigen-analysis of the covariance matrix.

## View it

- Locally: open `index.html` in a browser. No build step is needed.
- Online: enable GitHub Pages (Settings → Pages → Deploy from branch → `main`, `/ (root)`).
